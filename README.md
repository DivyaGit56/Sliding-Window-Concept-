# 🪟 Sliding Window Repository

Welcome to my **Sliding Window** repository! This repository contains a collection of sliding window problems implemented primarily in **Java**. It is designed to help beginners understand the sliding window technique and master interview-level problems involving arrays and strings.

---

# 📖 About

The **Sliding Window** technique is an efficient algorithmic approach used to solve problems involving **contiguous subarrays or substrings**. Instead of recomputing results for every window, it updates the current window incrementally, significantly reducing time complexity.

This repository includes:

* ✅ Beginner-friendly sliding window problems
* ✅ Fixed-size and variable-size window techniques
* ✅ Pattern-based interview questions
* ✅ Well-commented Java implementations
* ✅ Time and Space Complexity analysis
